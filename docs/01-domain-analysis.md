# Таҳлили соҳаи предметӣ: Гардиши электронии ҳуҷҷатҳо дар ташкилот

## 1. Тавсифи соҳа ва мушкилот
Соҳаи предметрии ин проект раванди таъминоти ҳуҷҷатии идоракунӣ (коргузорӣ) ва гардиши ҳуҷҷатҳои дохилии ташкилот мебошад. Айни замон дар бисёре аз ташкилотҳо ҳаракати ҳуҷҷатҳо (фармонҳо, мактубҳои хизматӣ, номаҳои воридотӣ ва содиротӣ) дар шакли коғазӣ ё тавассути мессенҷерҳои пароканда амалӣ карда мешавад. Ин боиси гум шудани ҳуҷҷатҳо, дароз кашидани мӯҳлати мувофиқасозии онҳо, набудани шаффофият дар марҳилаҳои баррасӣ ва душворӣ дар назорати интизоми иҷроия мегардад.
**Мақсади проект:** таҳияи веб-системаи сабуки гардиши электронии ҳуҷҷатҳо (СЭД), ки бақайдгирӣ, роҳёбӣ (маршрутизатсия), мувофиқасозӣ ва назорати иҷрои ҳуҷҷатҳоро дар дохили ташкилот автоматизатсия мекунад.

## 2. Ҳадди система (Scope)
| Дохил мешавад ба система | Дохил намешавад ба система |
| :--- | :--- |
| Бақайдгирии ҳуҷҷатҳои воридотӣ, содиротӣ ва дохилӣ | Ҳисоби бухгалтериявӣ ва ҳисоб кардани музд (маош) |
| Сохтан ва танзими маршрутҳои мувофиқасозии ҳуҷҷатҳо | Имзои электронии криптографии пурра бо токенҳои аппаратӣ (дар MVP — имзои электронии сода / статусҳо) |
| Мувофиқасозӣ ва тасдиқи электронии ҳуҷҷатҳо (статусҳо) | Идоракунии ҷадвали кадрӣ ва табелҳои вақти корӣ |
| Назорати иҷрои супоришҳо ва пайгирии мӯҳлатҳо | Сканкунӣ ва шинохти матни (OCR) ҳуҷҷатҳо |
| Ҷустуҷӯи ҳуҷҷатҳо аз рӯи атрибутҳо ва филтрҳо | Интегратсия бо системаҳои давлатии байниидоравии СЭД |

## 3. Шахсони манфиатдор (Stakeholders)
* **Роҳбарияти ташкилот (Директор):** манфиатдор аст дар бораи зуд имзо кардани ҳуҷҷатҳои калидӣ, шаффофияти равандҳо ва риояи мӯҳлати иҷрои супоришҳо.
* **Кормандони канцелярия / секретариат:** барои бақайдгирии аввалия, тақсими корреспонденция ва назорати фиристодан масъуланд.
* **Шӯъбаи ИТ (Администраторҳо):** манфиатдоранд дар кори устувори система дар сервери дохилии ташкилот, амнияти маълумот ва осонии маъмурикунонӣ.
* **Кормандони оддӣ:** манфиатдоранд дар бораи зуд пешниҳод кардани мактубҳои хизматӣ ва аризаҳо бидуни оворагарии коғазӣ.

## 4. Акторҳо (Actors)
| Актор | Коди нақш | Мақсадҳо | Амалҳои асосӣ |
| :--- | :--- | :--- | :--- |
| Администратор | `admin` | Корношоямии система, идоракунии ҳуқуқи корбарон | Идоракунии корбарон, нақшҳо, маълумотномаҳои шӯъбаҳо ва намудҳои ҳуҷҷатҳо |
| Секретариат / Канцелярия | `secretary` | Учёти дақиқ ва босуръати ҳамаи мактубҳои воридотӣ ва содиротӣ | Ҳуҷҷатҳои воридотӣ/содиротиро ба қайд мегирад, карточкаҳоро мезанад, ба роҳбарият медиҳад |
| Корманд (муаллифи ҳуҷҷат) | `employee` | Зуд пешниҳод кардани ҳуҷҷат ба мувофиқасозӣ ва пайгирии статуси он | Лоиҳаи ҳуҷҷатро месозад, ба мувофиқасозӣ мефиристад, дархостҳои худро мебинад |
| Роҳбар (шахси мувофиқкунанда) | `manager` | Саривақт баррасӣ кардани ҳуҷҷат, қабули қарор бидуни таъхир | Ҳуҷҷатҳои воридотии барои мувофиқаро мебинад, имзо мекунад (тасдиқ мекунад) ё рад мекунад |

## 5. Равандҳои бизнес
### Раванди 1: Бақайдгирӣ ва баррасии ҳуҷҷати воридотӣ
* **Триггер:** Ворид шудани мактуб ё ҳуҷҷати расмӣ ба ташкилот.
* **Иштирокчиён:** `secretary`, `manager`, `employee` (иҷрокунанда).
* **Қадамҳо:**
  1. Секретар ҳуҷҷатро мегирад, маълумоти онро ба система дохил мекунад (рақам, сана, муалриф, мавзӯъ) — статуси `registered`.
  2. Роҳбар огоҳинома мегирад, ҳуҷҷатҳоро баррасӣ мекунад ва резолюция мегузорад (иҷрокунандаи масъул ва мӯҳлатро таъин мекунад).
  3. Система ҳуҷҷатро ба статуси `in_progress` мегузаронад ва ба иҷрокунанда медиҳад.
* **Натиҷа:** Ҳуҷҷати бақайдгирифташуда бо резолюцияи роҳбар ва иҷрокунандаи таъиншуда.
* **Истисноҳо:** Ҳуҷҷат хато ба суроғаи дигар ворид шудааст — секретариат онро бармегардонад ё роҳнамоӣ мекунад (статуси `returned`).

### Раванди 2: Мувофиқасозии ҳуҷҷати дохилӣ (фармон / мактуби хизматӣ)
* **Триггер:** Эҳтиёҷи корманд ба баровардани ҳуҷҷати дохилӣ ё амр.
* **Иштирокчиён:** `employee`, `manager`, `director`.
* **Қадамҳо:**
  1. Корманд варақаи ҳуҷҷатро дар система пур мекунад ва файлро замима мекунад — статуси `draft`.
  2. Корманд ҳуҷҷатро ба мувофиқасозӣ мефиристад — статуси `pending`.
  3. Роҳбари шӯъба ҳуҷҷатро месанҷад ва мувофиқа мекунад (статуси `approved_by_manager`) ё бо шарҳ рад мекунад (статуси `rejected`).
  4. Директор тасдиқи ниҳоиро иҷро мекунад (статуси `approved`).
* **Натиҷа:** Ҳуҷҷати дохилии тасдиқшуда, ки рақами қайди уникалӣ гирифтааст.
* **Истисноҳо:** Ҳуҷҷат дар ҳар кадом марҳила рад карда мешавад; муаллиф онро мукаммал карда, аз нав мефиристад.

### Раванди 3: Назорати иҷрои супоришҳо
* **Триггер:** Фарорасии мӯҳлати иҷро ё санҷиши статуси вазифа аз рӯи ҳуҷҷат.
* **Иштирокчиён:** `manager`, `employee`.
* **Қадамҳо:**
  1. Роҳбар ё система ҳуҷҷатҳоеро пайгирӣ мекунад, ки мӯҳлати иҷрояшон ба охир расида истодааст.
  2. Иҷрокунанда корро ба охир мерасонад ва ҳисоботи иҷроро замима мекунад.
  3. Роҳбар ҳисоботро месанҷад ва супоришро мепӯшад (статуси `completed`).
* **Натиҷа:** Супориш бо статуси «Иҷро шуд» ба архив гузаронида шуд.
* **Истисноҳо:** Вайрон кардани мӯҳлати иҷро — система ҳуҷҷатро бо ранги сурх нишон медиҳад (статуси `overdue`).

## 6. Объектҳои додаҳо
| Объект | Атрибутҳои асосӣ | Робитаҳо |
| :--- | :--- | :--- |
| Корбар (`users`) | логин, парол, ФИО, нақш, фаъол будан | бо корманд ва шӯъба алоқаманд аст |
| Шӯъба (`departments`) | ном, роҳбар | кормандонро дар бар мегирад |
| Ҳуҷҷат (`documents`) | рақами рег., намуд (воридотӣ/содиротӣ/дохилӣ), мавзӯъ, матн, санаи сохт, статус | аз тарафи корбар сохта шудааст, ба шӯъба тааллуқ дорад |
| Маршрути мувофиқасозӣ (`approvals`) | ҳуҷҷат_id, мувофиқкунанда_id, статус (интизорӣ/мувофиқа шуд/рад шуд), шарҳ, санаи ҷавоб | ба ҳуҷҷати мушаххас вобаста аст |
| Супориш (`tasks`) | матни супориш, санаи дода шудан, мӯҳлати иҷро, статус | ба ҳуҷҷат ва иҷрокунанда вобаста аст |

## 7. Қоидаҳои бизнес
* `BR-01`: Санаи иҷрои супориш наметавонад пештар аз санаи сохта шудани он бошад.
* `BR-02`: Ҳуҷҷат наметавонад статуси «Тасдиқ шуд»-ро гирад, то даме ки ҳамаи мақомоти ҳатмии мувофиқасозӣ онро маъқул накунанд.
* `BR-03`: Рақами бақайдгирии уникалии ҳуҷҷат ба таври худкор сохта мешавад ва такрор шуда наметавонад.
* `BR-04`: Корманди аз кор озодшуда ё басташуда (`is_active = 0`) ҳуқуқи ба система ворид шудан ва имзо кардани ҳуҷҷатҳоро надорад.
* `BR-05`: Фақат шахси мувофиқкунандаи таъиншуда ё роҳбар ҳуқуқ дорад ҳуҷҷатро бо нишон додани сабаб рад кунад.

## 8. Глоссарий
* **Ҳуҷҷат (`document`):** Ахбороти расмӣ дар ноқили электронӣ, ки мувофиқи қоидаҳои муқарраршуда ба қайд гирифта шудааст.
* **Ҳуҷҷати воридотӣ (`incoming`):** Ҳуҷҷате, ки аз шахсони сеюм ё идораҳои дигар ба ташкилот ворид шудааст.
* **Ҳуҷҷати содиротӣ (`outgoing`):** Ҳуҷҷате, ки аз ташкилот ба суроғаҳои беруна фиристода мешавад.
* **Ҳуҷҷати дохилӣ (`internal`):** Ҳуҷҷате, ки танҳо дар дохили ташкилот гардиш мекунад (фармонҳо, мактубҳои хизматӣ).
* **Мувофиқасозӣ (`approval`):** Раванди пешакӣ баррасӣ ва маъқул кардани лоиҳаи ҳуҷҷат аз ҷониби шахсони ваколатдор.
* **Резолюция (`resolution`):** Дастури роҳбар оид ба иҷрои ҳуҷҷат, ки дар система сабт шудааст.
* **Иҷрокунанда (`executor`):** Корманде, ки барои иҷрои амалии супориш аз рӯи ҳуҷҷат масъул аст.
* **Статус (`status`):** Ҳолати ҷории ҳуҷҷат дар давраи ҳаёт (проект, дар баррасӣ, тасдиқ шуд, рад шуд).

## 9. Сарчашмаҳо
1. Дастури намунавӣ оид ба коргузорӣ дар ташкилот ва муассисаҳо.
2. Мусоҳиба бо мутахассисони соҳаи коргузорӣ ва таҳлили журналҳои коғазии мавҷудаи бақайдгирии мактубҳои воридотӣ.
