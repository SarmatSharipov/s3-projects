ВАЗИФАИ ТЕХНИКӢ (ТЗ)
Мавзӯъ: Коркарди веблоиҳаи гардиши электронии ҳуҷҷатҳо дар ташкилот
Иҷрокунанда: Шарипов Сармат Ҷонибекович

1. Муқаддима ва Мақсади Лоиҳа
Мақсади асосии ин лоиҳа — таҳия ва ҷорӣ намудани системаи вебии гардиши электронии ҳуҷҷатҳо (EDMS) дар ташкилот мебошад. Система барои рақамикунонии пурраи ҷараёни кор бо ҳуҷҷатҳо, баланд бардоштани интизоми иҷрокунандагон, кам кардани хароҷоти коғазӣ ва суръатбахшии мувофиқасозии ҳуҷҷатҳо пешбинӣ шудааст.

Вазифаҳои асосӣ: Бақайдгирии марказонидашудаи ҳуҷҷатҳои воридотӣ, содиротӣ ва дохилӣ; тақсими худкори супоришҳо; назорати мӯҳлати иҷро ва пешниҳоди ҳисоботҳо.

2. Сохтори Нақшҳои Корбарон ва Ҳуқуқи дастрасӣ (User Roles)
Дар система тақсимоти қатъии ҳуқуқҳо аз рӯи нақшҳои зерин амалӣ карда мешавад:

Девонхона (Канцелярия): Қабул, сканкунӣ, бақайдгирии рақамӣ ва фиристодани ҳуҷҷатҳо ба роҳбарият ё шӯъбаҳои дахлдор; баҳисобгирии ҳуҷҷатҳои содиротӣ.

Роҳбар (Director / Manager): Баррасии ҳуҷҷатҳо, навиштани резолютсияҳо (дастурҳо), таъини иҷрокунандагони асосӣ ва иловагӣ, тасдиқ ё рад кардани ҳуҷҷатҳои пешниҳодшуда.

Сардори шӯъба (Department Head): Тақсими супоришҳои роҳбар ба кормандони зериدست ва назорати иҷрои онҳо дар сатҳи шӯъба.

Корманд (Employee): Иҷрои супоришҳои воридшуда, таҳияи ҳисоботҳо оид ба иҷро ва фиристодани ҳуҷҷатҳо тавассути масири мувофиқасозӣ.

Администратор (Administrator): Идоракунии корбарон, сохтори шӯъбаҳо, назорати амният, эҷоди нусхаҳои эҳтиётии (backup) базаи додаҳо.

3. Талаботи Функсионалӣ (Functional Requirements)
Бақайдгирии ҳуҷҷатҳо: Ворид кардани рақами тартибӣ, санаи воридшавӣ, намуди ҳуҷҷат (воридотӣ, содиротӣ, дохилӣ), маълумот дар бораи фиристанда/қабулкунанда ва замима кардани файли сканшуда (форматҳои PDF, DOC, JPG).

Низомбандии ҳуҷҷатҳо: Ҷудо кардани ҳуҷҷатҳо ба се гурӯҳи асосӣ: воридотӣ, содиротӣ ва дохилӣ бо имконияти гурӯҳбандӣ аз рӯи мавзӯъ ва муҳимвӣ.

Резолютсияи роҳбар: Имконияти хаттӣ ё интихобии резолютсия аз ҷониби роҳбар, муайян кардани муҳлити иҷро ва таъини иҷрокунандаи масъул.

Идоракунии супоришҳо (Tasks & Workflow):

Таъини супоришҳо бо муҳлити муайяни соатӣ ё рӯзона.

Пешниҳоди ҳисобот ва файли натиҷавӣ аз ҷониби иҷрокунанда пас аз анҷоми кор.

Масири мувофиқа (Approval Route / Routing): Ҳуҷҷат пеш аз тасдиқи ниҳоӣ бояд пайдарпай (sequential) аз чанд масъул (масалан: ҳуқуқшинос, сармуҳосиб, муовини роҳбар) гузарад. Ҳар кадом метавонад онро «Тасдиқ кунад» ё бо сабаби радкунӣ «Баргардонад».

Назорати иҷро ва огоҳиҳо (Control & Notifications): Низоми худкори назорат бар супоришҳое, ки мӯҳлаташон гузаштааст (фарорасии санаи анҷом), бо нишон додани ранги огоҳкунанда (масалан, сурх барои мӯҳлатгузашта).

Ҷустуҷӯ ва Филтркунии пешрафта: Ҷустуҷӯи фаврӣ аз рӯи рақами ҳуҷҷат, санаи қабул, калимаҳои калидӣ дар мавзӯъ ва намуди ҳуҷҷат.

Модули Ҳисоботҳо (Reporting): Таҳия ва баровардани ҳисоботҳо оид ба миқдори ҳуҷҷатҳои иҷрошуда, иҷронашуда ва дар ҳолати баррасӣ буда барои давраи интихобшуда (моҳ, семоҳа, сол) бо имконияти содирот ба Excel/PDF.

4. Сохтори Базаи Додаҳо (Database Schema — Ҷадвалҳои асосӣ)
Барои амалинамоии ин лоиҳа базаи додаҳои MySQL бо ҷадвалҳои взаимосвязанный (вобаста) истифода мешавад:

users — Маълумот дар бораи корбарон (ID, ному насаб, логин, парол, нақш, ID-и шӯъба).

departments — Шӯъба ва сохторҳои ташкилот (ID, номи шӯъба).

documents — Маълумоти асосии ҳуҷҷатҳо (ID, рақам, сана, мавзӯъ, намуд, файли сканшуда, фиристанда, корбари эҷодкунанда).

resolutions — Резолютсия ва дастурҳои роҳбар (ID, ID-и ҳуҷҷат, ID-и роҳбар, матни резолютсия, сана).

tasks — Супоришҳо ва иҷрокунандагон (ID, ID-и ҳуҷҷат, ID-и иҷрокунанда, муҳлати иҷро, ҳолат/статус, ҳисоботи иҷро).

approvals — Масири мувофиқасозии ҳуҷҷатҳо (ID, ID-и ҳуҷҷат, ID-и шахси мувофиқкунанда, тартиби қадам, статус: тасдиқшуда/радшуда, шарҳ).

5. Технологияҳои Истифодашаванда (Tech Stack)
Frontend: HTML5, CSS3, JavaScript, Bootstrap 5 (барои таъмини мутобиқшавӣ ба экранҳои гуногун ва тарҳи зебо).

Backend: PHP (барои коркарди логикаи барнома, кор бо сессияҳо ва амният).

Database Management System: MySQL (тавассути phpMyAdmin ё XAMPP).

Server environment: Apache (XAMPP localhost).
