Лоиҳа: «Коркарди веблоиҳаи гардиши электронии ҳуҷҷатҳо дар ташкилот» (EDMS)
Корҳои лабораторӣ №4 · Диаграммаи алоқаманд: `use-case.puml`

## UC-02. Бақайдгирии ҳуҷҷат

| Майдон | Мазмун |
|---|---|
| **Рамз / Ном** | UC-02 · Бақайдгирии ҳуҷҷат |
| **Актор** | Девонхона (Chancellery). Актори дуюм: Администратор (дорои ҳамин ҳуқуқ) |
| **Мақсад** | Ҳуҷҷати воридотӣ, содиротӣ ё дохилиро дар системаи марказонидашуда сабт кардан ва барои мувофиқа ва резолютсия омода намудан |
| **Триггер** | Ҳуҷҷат ба ташкилот қабул шуд ё барои фиристодан омода аст; актор тугмаи «+ Бақайдгирии ҳуҷҷат»-ро пахш мекунад |

### Пешшартҳо (Предусловия)
1. Актор аутентификатсия шудааст (UC-01), нақши ӯ `chancellery` ё `admin` аст.
2. Ҳуҷҷати коғазӣ скан шудааст (барои замимаи ихтиёрӣ, UC-03).
3. Пайвастшавӣ ба базаи додаҳои MySQL фаъол аст.

### Ҷараёни асосӣ (Основной поток)
1. Актор саҳифаи `document_add.php`-ро мекушояд.
2. Система формаро нишон медиҳад: рақами тартибӣ бо қимати пешниҳодшуда (`СОЛ-0001`), санаи имрӯза, намуд, муҳимӣ.
3. Актор рақамро тасдиқ ё ислоҳ мекунад, санаи воридшавиро, намуди ҳуҷҷатро (воридотӣ / содиротӣ / дохилӣ), дараҷаи муҳимиро, мавзӯъро, фиристанда ва қабулкунандаро ворид мекунад.
4. Актор файли сканшударо интихоб мекунад (PDF, DOC, DOCX, JPG) ва «Захира кардан»-ро пахш мекунад.
5. Система токени CSRF, нақши актор ва дурустии намуд ва муҳимиро месанҷад.
6. Система формати файлро месанҷад, онро бо номи тасодуфӣ дар `uploads/` нигоҳ медорад (UC-03, `<<extend>>`).
7. Система сатри нав ба ҷадвали `documents` илова мекунад: `status = 'registered'`, `created_by` = ID-и актор.
8. Система ҳуҷҷатро дар саҳифаи `document_view.php?id=…` нишон медиҳад ва паёми «Ҳуҷҷат бақайд гирифта шуд» мебарорад.

### Ҷараёнҳои алтернативӣ (Альтернативные потоки)
- **A1. Майдони ҳатмӣ холӣ аст** (5): браузер ё система сабтро намепазирад, форма бо қиматҳои ворид кардашуда боқӣ мемонад, актор майдонро пур мекунад ва ба қадами 4 бармегардад.
- **A2. Намуд ё муҳимӣ дар рӯйхати иҷозатдодашуда нест** (5): система бекор мекунад, паёми «Маълумот нодуруст» (flash, `danger`) нишон медиҳад ва формаро аз нав мекушояд.
- **A3. Файл замима нашудааст ё формат нодуруст аст** (6): файл қабул намешавад, ҳуҷҷат бе замима сабт мешавад (`scan_file = NULL`). Актор метавонад баъдтар скани дурустро илова кунад.
- **A4. Сессия ба поён расидааст** (5): система ба `login.php` равона мекунад, маълумот сабт намешавад.
- **A5. Токени CSRF нодуруст аст** (5): система хатои 400 бармегардонад, ҳеҷ чиз сабт намешавад.
- **A6. Хатои базаи додаҳо** (7): сабт анҷом намеёбад, актор хатогиро мебинад, файли боргирифташуда дар `uploads/` монда метавонад.

### Пасшарт (Постусловие)
- **Муваффақият:** дар `documents` сатри нав бо `status = 'registered'` ва рақами ягона мавҷуд аст; файли скан (агар буд) дар `uploads/` нигоҳ дошта шудааст; ҳуҷҷат дар рӯйхат ва ҷустуҷӯ (UC-04) дастрас аст ва барои масири мувофиқа (UC-05) ё резолютсия (UC-08) омода аст.
- **Нокомӣ:** сатр дар `documents` илова намешавад; ҳолати система тағйир намеёбад.

## UC-08. Гузоштани резолютсия

| Майдон | Мазмун |
|---|---|
| **Рамз / Ном** | UC-08 · Гузоштани резолютсия |
| **Актор** | Роҳбар (Manager / Director). Актори дуюм: Администратор. Актори дуюмдараҷа: Корманд (иҷрокунанда, супориш мегирад) |
| **Мақсад** | Дастури хаттии роҳбар оид ба ҳуҷҷат сабт кардан, иҷрокунанда ва мӯҳлати иҷроро муайян намудан |
| **Триггер** | Роҳбар ҳуҷҷати бақайдгирифташударо барои баррасӣ мекушояд |

### Пешшартҳо (Предусловия)
1. Актор аутентификатсия шудааст, нақши ӯ `director` ё `admin` аст.
2. Ҳуҷҷат дар система мавҷуд аст ва ҳолати он `registered`, `review` ё `approved` аст (барои ҳуҷҷати `done` резолютсияи нав маъно надорад).
3. Агар масири мувофиқа таъин шуда бошад, ҳамаи қадамҳо `approved` мебошанд (`documents.status = 'approved'`).
4. Дар базаи додаҳо ҳадди аққал як корманд (иҷрокунанда) вуҷуд дорад.

### Ҷараёни асосӣ (Основной поток)
1. Актор саҳифаи `document_view.php?id=…`-ро мекушояд ва мазмуни ҳуҷҷатро (мавзӯъ, замимаи скан) меомӯзад.
2. Система блоки «Резолютсияҳо» ва формаи резолютсияро нишон медиҳад.
3. Актор матни резолютсияро менависад.
4. Актор аз рӯйхат иҷрокунандаи масъулро интихоб мекунад (UC-09, `<<include>>`).
5. Актор мӯҳлати иҷроро (сана ва соат) мегузорад ва «Сабт ва таъини иҷрокунанда»-ро пахш мекунад.
6. Система токени CSRF ва нақши актор (`director` / `admin`) -ро месанҷад.
7. Система дар як транзаксия: сатри нав ба `resolutions` (`document_id`, `director_id`, `text`) ва сатри нав ба `tasks` (`resolution_id`, `executor_id`, `assigned_by`, `deadline`, `status = 'new'`) илова мекунад.
8. Система `documents.status`-ро ба `'in_progress'` иваз мекунад (агар ҳолати пешин `registered`, `review` ё `approved` буд).
9. Система саҳифаро нав мекунад: резолютсия дар рӯйхат ва супориш бо мӯҳлат пайдо мешавад, паёми «Резолютсия сабт шуд ва супориш таъин гардид» нишон дода мешавад.
10. Иҷрокунанда супоришро дар саҳифаи «Супоришҳо» мебинад (UC-10).

### Ҷараёнҳои алтернативӣ (Альтернативные потоки)
- **A1. Матн холӣ аст ё иҷрокунанда / мӯҳлат интихоб нашудааст** (5): форма сабт намешавад, майдони холӣ қайд карда мешавад, актор онро пур мекунад ва ба қадами 5 бармегардад.
- **A2. Роҳбар иҷрокунандагони иловагӣ мехоҳад** (после 9): актор формаро такроран пур мекунад; ҳар резолютсия ва супориши нав алоҳида сабт мешавад (як ҳуҷҷат ба чанд иҷрокунанда).
- **A3. Хатои транзаксия** (7): `ROLLBACK`, на резолютсия ва на супориш сабт намешавад, ҳолати ҳуҷҷат тағйир намеёбад, актор паёми хатогӣ мегирад.
- **A4. Ҳуҷҷат дар `rejected` аст** (2): резолютсия гузошта мешавад, вале `documents.status` худ ба худ тағйир намеёбад, то Девонхона ҳуҷҷатро ислоҳ ва аз нав мувофиқа накунад.
- **A5. Сессия ба поён расидааст ё токени CSRF нодуруст аст** (6): мутобиқан ба `login.php` равона мекунад ё хатои 400 мебарорад, маълумот сабт намешавад.
- **A6. Актор нақши мувофиқ надорад** (1, 6): форма нишон дода намешавад, амали POST иҷро намегардад.

### Пасшарт (Постусловие)
- **Муваффақият:** дар `resolutions` сатри нав бо матни роҳбар ва санаи сабт ҳаст; дар `tasks` сатри нав бо `status = 'new'` ва мӯҳлати муайян ҳаст; `documents.status = 'in_progress'`; иҷрокунанда супоришро мебинад; назорати мӯҳлат (UC-12) оғоз мешавад ва дар сурати гузаштани мӯҳлат ранги сурх (UC-13) нишон дода мешавад.
- **Нокомӣ:** ҷадвалҳои `resolutions` ва `tasks` бетағйир мемонанд.
