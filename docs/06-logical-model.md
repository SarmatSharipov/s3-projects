## 2. Нормализатсия (1ШН → 2ШН → 3ШН)

### Шакли якуми нормалӣ (1ШН)
- **Вайронкунӣ:** Майдонҳои таркибӣ ва якчанд қимат дар як ҳуҷайра (масалан, "№01/2026 (01.03.2026)" ва "Абдуллоев Ш. (Шӯъбаи IT)").
- **Ислоҳ:** Ҳамаи майдонҳо ба қиматҳои атомарӣ ҷудо карда шуданд (`number`, `doc_date`, `full_name`, `department_name`). Ҷадвал калиди асосиро соҳиб шуд.

### Шакли дуюми нормалӣ (2ШН)
- **Вайронкунӣ:** Вобастагии қисмӣ (пайвандҳои таркибӣ баъзе атрибутҳоро қисман муайян мекарданд).
- **Ислоҳ:** Ҳамаи ҷадвалҳо калиди соддаи суррогатии `id (PRIMARY KEY)` гирифтанд. Ҳамаи атрибутҳои ғайрикалидӣ комилан аз калиди асосии худ вобаста шуданд.

### Шакли сеюми нормалӣ (3ШН)
- **Вобастагиҳои транзитивӣ:**
  1. `document -> executor -> department` (Шӯъба аз иҷрокунанда вобаста буд, на бевосита аз ҳуҷҷат).
  2. `document -> director -> resolution` (Матни резолюция аз директор ва ҳуҷҷат вобаста буд).
- **Ислоҳ:** Вобастагиҳои транзитивӣ ба ҷадвалҳои алоҳида бароварда шуданд: `departments`, `users`, `resolutions`, `tasks`, `approvals`.

## 4. Алоқаҳо ва Маҳдудиятҳо

### Алоқаҳо:
- `departments` ||--o{ `users`: (1:N) Як шӯъба бисёр корбар дорад.
- `users` ||--o{ `documents`: (1:N) Корбар метавонад чанд ҳуҷҷат эҷод кунад.
- `documents` ||--o{ `resolutions`: (1:N / 1:1) Алоқа ба резолюцияҳо.
- `documents` ||--o{ `tasks`: (1:N) Алоқа ба супоришҳо.
- `documents` ||--o{ `approvals`: (1:N) Алоқа ба тасдиқкунандагон.
- `users` ||--o{ `tasks`: (1:N) Корбар ҳамчун иҷрокунанда ё таъинкунанда.

### Маҳдудиятҳои бутунӣ (Integrity Constraints):
1. **UNIQUE:** `users.login`
2. **ON DELETE CASCADE:** Нест кардани ҳуҷҷат ба таври автоматӣ `resolutions`, `tasks` ва `approvals`-и дахлдорро нест мекунад.
3. **ON DELETE SET NULL:** Нест кардани шӯъба майдони `users.department_id`-ро ба NULL табдил медиҳад.
