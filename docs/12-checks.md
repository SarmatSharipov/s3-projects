# Lab 12 — EDMS

PDO + Repository + CRUD + ҷустуҷӯ/филтр/саҳифабандӣ + валидатсия + PRG + ҳисобот.

## Санҷиш
1. `database/schema.sql` (ва додаҳои санҷишӣ) иҷро шуд.
2. Сервер бо `php -S localhost:8000 -t public` (ё XAMPP) ба кор андохта шуд[cite: 32, 50].
3. `/documents` — рӯйхат бо саҳифабандӣ, филтрҳо ва нишондоди «Ёфт шуд...» кушода шуд[cite: 32, 34, 50].
4. Ҷустуҷӯи `' OR 1=1 --` → `0` сабт, хатои SQL рух надод[cite: 32, 50].
5. `/documents/create` → валидатсияи серверӣ (422 ҳангоми хато), пас аз сабти дуруст редиректи `302` (PRG)[cite: 16, 34, 50].
6. Таҳрири сабт ва нест кардан тавассути `POST` (PRG)[cite: 12, 16, 50].
7. `/reports/status` — саҳифаи ҳисобот дуруст намоиш дода шуд[cite: 50, 51].
